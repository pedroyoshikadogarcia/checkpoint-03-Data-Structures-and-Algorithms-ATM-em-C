**Descrição do Projeto**

Este projeto é consiste no desenvolvimento de um ATM (Caixa eletronico) utilizando a linguagem C.

O projeto aplica conceitos aprendidos em aula, como:

- Estrutura de Descisão ('switch-case')
-Estrutura de Repetição ('dor-while')
- Modularização com funções
- Validação de dados
- Manipulação de variáveis
- Organização de código

---

**Funcionalidades implementadas**

- Consulta de saldo
- Realização de saque
- Realização de depósito
- Extrato bancário
- Limite diário de saque
- Validação de operações inválidas
- Menu interativo
- Histórico das últimas operações
- Interface textual organizada
